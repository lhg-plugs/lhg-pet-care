# /lhg-pet-care:pet-profile —— 宠物档案建档

用户输入在 `$ARGUMENTS` 中：`[宠物信息] [--update]`。

加载 `lhg-pc-profile` skill（第 3 节建档七步法）执行；多宠物家庭为每只宠独立建档，文件名 `profile-<名字>.json`。

> **健康声明**：档案仅用于养护计划参考，不是医疗记录；既往病史描述请以兽医诊断为准。

## 流程

1. **收集七件事**：物种/品种、年龄、体重（必须带单位 kg）、性别与绝育状态、疫苗史（末次接种日期+种类）、过敏/慢性病史、生活环境。
2. **缺项处理**：缺物种或体重 → 停下来问，不许用"常见品种平均体重"脑补；缺疫苗史 → 标 `unknown` 并提醒"尽快咨询兽医补档"。
3. **写 profile.json**：字段见 skill 第 2 节 schema；`--update` 时只改用户明确说的字段，其余保留。
4. **用户确认**：把档案摘要念给用户听，确认无误再结束。

## 反模式
- 一只宠物的体重写进另一只宠物的档案（多宠家庭高发）。
- kg/lb/斤混用：档案里体重只许用 kg。
