# /lhg-pet-care:pet-schedule —— 养护时间表生成

用户输入在 `$ARGUMENTS` 中：`[profile.json 路径] [--year 年份]`，缺省当年。

加载 `lhg-pc-schedule` skill（第 3 节排期五步法）执行；可分派给 `schedule-reviewer` agent 做冲突复核。

> **健康声明**：时间表仅供日常养护参考，具体接种与用药方案请遵医嘱；日期临近请以兽医/疫苗本记录为准。

## 流程

1. **读档案**：从 profile.json 取物种、年龄阶段、体重、疫苗史、绝育状态。
2. **排疫苗**：首免（如未完成）按 3~4 周间隔排；加强针按"上针 +11~12 个月"排；同种疫苗两针间隔 <21 天直接报错重排。
3. **排驱虫**：体外每月、体内每 3 个月为默认节拍（以兽医建议为准）；不与疫苗同天；同一天只排一种驱虫药。
4. **排体检/护理**：成年每年一体检、老年每半年一；洁牙、绝育复查按需插入。
5. **冲突自检**：跑一遍 lhg-pc-schedule 第 5 节冲突清单，输出 `schedule-<年份>.md`（日期/事项/备注三列表格）。

## 输出要求
- 每个日期条目带"备注"列：如"加强针请携带疫苗本"、"驱虫药遵医嘱按体重核算剂量"。
- 文件顶部带健康声明块。
